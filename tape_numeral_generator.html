Tape Numerals (prototype)

Two-digit numbers (01–99) built from a 7-segment layout, each segment drawn as its own rectangular block. At zero drift the blocks butt together at clean 90° joins (tape-1.png). Turning up position/angle drift nudges and rotates every block independently around its own center, so joins gap, overlap and go slightly off-square — the look of tape actually stuck down by hand (tape-2.png). The Counter slider opens up a real hollow between the left/right verticals, so 0/6/8/9 read as holes rather than fused blobs — 0 keeps the chunky fused look, higher values trade a bit of that bluntness for legibility.

Prototype for the tape-numeral direction (tape-1.png / tape-2.png references). Segment on/off per digit follows a standard 7-segment table; drift is deterministic per seed, so re-rendering with the same seed at a different drift amount scales the same block-by-block wobble up or down rather than reshuffling it.
